# PageMarks Privacy Statement

PageMarks does not collect, transmit, sell, or share personal information.

All highlights, comments, reactions, tags, sticky-note positions, settings, and page URLs are stored locally in the user's Chrome profile through `chrome.storage.local`. The extension has no backend, account system, analytics SDK, advertising SDK, remote scripts, or network requests.

Users can export their data manually as JSON, Markdown, CSV, or HTML. Exported files are created locally by the browser. Users can delete individual annotations or all PageMarks data from the library.

PageMarks reads webpage text and links only to create and restore annotations requested by the user. This processing occurs inside the browser and is not transmitted elsewhere.
